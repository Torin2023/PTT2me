# Оптимизация и устойчивость PTT2me

Пользователь 2026-09-06 одобрил выполнение предложений отдельными коммитами, общее тестирование и релиз без дополнительных согласований; дополнительно потребовал отдельно исправить отказ вставки в ChatGPT. Исходная база: ca2a465 (1.2.1). Следующая версия: 1.3.0, поскольку меняется архитектура восстановления и последовательной диктовки.

## Цель

Уменьшить размер app, убрать вычисления и регулярный опрос из AppKit-потока, восстановить вставку в ChatGPT по установленной причине, обеспечить повторную диктовку во время восстановления clipboard и восстановление ASR после сбоя. Ввести воспроизводимые измерения и выпустить проверенный preview.

## Контракты

- Только arm64, macOS 13+. Каждое вложенное Mach-O содержит ровно arm64.
- CPAL stream создаётся и уничтожается на главном потоке. Callback не выполняет выделения/фильтрацию; завершённая запись обрабатывается в фоне.
- Существующая модель gigaam-v3-rnnt-v1 и immutable records сохраняются. ASR CPU/2 потока остаётся базой до сравнительных речевых измерений.
- Один ASR child с ограниченным бинарным протоколом и watchdog. Идентификаторы сессии/операции исключают поздние ответы. Child не вызывает AppKit/TCC и не записывает аудио/текст в logs/files.
- Одна запись/распознавание одновременно; максимум одна ожидающая следующая вставка. Запись следующей фразы разрешена во время восстановления предыдущего clipboard, а clipboard-транзакции строго последовательны.
- Текущие short-press/combination semantics, 25 s capture limit, 180 ms release tail, secure-field checks, focus revalidation и ownership/changeCount clipboard сохраняются.
- AX IPC имеет явные ограничения времени. Clipboard целиком сохраняется либо операция отказывается до его изменения; неполные снимки запрещены.
- События будят run loop; периодические таймеры остаются только для реальных deadlines/ограниченного восстановления. Нельзя задерживать PTT или выход за счёт join заблокированного потока.
- SHA-256 модели, updater signatures, HTTPS/path/symlink checks и лицензии сохраняются.
- Никаких автоматических загрузок/замены моделей, секретов в Git, force push, изменений основной dirty-папки.

## Доступные границы выпуска

На старте обнаружено 0 valid code-signing identities. Поэтому Developer ID/notarization фактически недоступны; нельзя заявлять их реализацию. Сохраняется честный unsigned preview и существующая безопасная TCC migration для ad-hoc. Новые engine/provider/model варианты включаются только после доказательства качества/скорости. Платные аккаунты и новый секрет не создаются автоматически.

## Проверка

Фокусные regression-тесты каждого изменения и независимый review, затем полный macOS gate, shell/bundle/release checks, GUI insertion fixture и безопасные draft-проверки ChatGPT/браузера без отправки сообщений. Полный физический Fn/диктовочный сценарий отделять от имитированных событий; непроверенные пункты не отмечать PASS. Публикация авторизована пользователем, но фактические ошибки/непройденные обязательные release gates не скрывать.
