# Локальный DMG-релиз PTT2me

## Цель

Сделать локальный релиз PTT2me 1.0.0 воспроизводимым и получить проверенный
установочный образ для Apple Silicon. Релиз не предназначен для публичного
распространения через Gatekeeper: приложение сохраняет существующую ad-hoc
подпись и не проходит нотариализацию Apple.

## Релизные артефакты

Скрипт `scripts/build-dmg.sh` создаёт в `dist/`:

- `PTT2me.app`;
- `PTT2me-1.0.0-macos-arm64.dmg`;
- `PTT2me-1.0.0-macos-arm64.dmg.sha256`.

Существующий ZIP-архив не удаляется и не изменяется. Версия для имени DMG
читается из `Cargo.toml`, поэтому имя артефакта совпадает с версией приложения.

## Содержимое DMG

В корне смонтированного образа находятся только:

- `PTT2me.app`;
- символическая ссылка `Applications` на `/Applications`.

Пользователь устанавливает приложение перетаскиванием `PTT2me.app` на ссылку
`Applications`. Фон, нестандартный значок тома и автоматическая настройка окна
Finder не входят в локальный релиз.

## Процесс сборки

1. Скрипт проверяет, что выполняется на Apple Silicon и что доступны системные
   утилиты macOS, необходимые для создания образа.
2. `scripts/build-app.sh` заново собирает и проверяет `dist/PTT2me.app`.
3. Во временном каталоге создаётся содержимое будущего образа.
4. `hdiutil` формирует сжатый read-only DMG с предсказуемым именем тома.
5. Готовый образ монтируется без автоматического открытия Finder.
6. Проверяется наличие приложения и корректной ссылки `Applications`, а
   вложенный app bundle повторно проверяется через `scripts/check-bundle.sh`.
7. Образ гарантированно отключается, после чего для него создаётся SHA-256.

Временные каталоги и точки монтирования создаются через `mktemp`. Обработчик
выхода отключает смонтированный образ и удаляет только созданные скриптом
временные данные. Готовый DMG сначала создаётся под временным именем и заменяет
целевой файл только после успешной проверки.

## Обработка ошибок

Любая ошибка сборки, создания, монтирования или проверки DMG завершает скрипт
с ненулевым кодом. Частичный целевой DMG и неверная контрольная сумма не должны
оставаться в `dist/`. Диагностическое сообщение указывает этап, на котором
произошёл сбой.

## Документация

README получает короткую команду сборки DMG, список создаваемых файлов и явное
предупреждение о том, что локальная ad-hoc сборка не нотариализована.

## Проверка

Готовность релиза подтверждается следующими проверками:

1. все тесты Rust проходят;
2. `cargo clippy --all-targets -- -D warnings` проходит;
3. `scripts/check-bundle.sh dist/PTT2me.app` проходит;
4. DMG успешно создаётся, монтируется и содержит ровно два ожидаемых элемента;
5. приложение внутри DMG проходит `scripts/check-bundle.sh`;
6. опубликованная SHA-256 совпадает с пересчитанной контрольной суммой.
