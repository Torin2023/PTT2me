# Красный значок критического состояния PTT2me

## Цель

Когда диктовка недоступна и требуется действие пользователя либо исправление
постоянной ошибки, PTT2me должен показывать в строке меню заметный красный
треугольник. Временные ошибки не должны выглядеть как постоянная
неработоспособность.

## Отображение состояний

- `PermissionBlocked(_)` использует SF Symbol
  `exclamationmark.triangle.fill` с красной hierarchical-конфигурацией.
- `Error { recoverable: false, .. }` использует тот же красный треугольник.
- `Error { recoverable: true, .. }` сохраняет обычный template-символ
  `exclamationmark.circle.fill`.
- `Starting`, `Ready`, `Recording` и `Recognizing` не меняются.

Красный стиль задаётся явно в `MenuProjection`, а не выводится из строки с
именем SF Symbol. Это сохраняет независимость визуальной критичности от выбора
конкретного символа.

## AppKit-рендеринг

Красный треугольник создаётся тем же проверенным способом, что и красный значок
записи: через `NSImageSymbolConfiguration` с hierarchical system red и
non-template изображением. `contentTintColor` не используется.

Меню не перестраивается. `MenuBar::render` продолжает менять только заголовок,
изображение и pulse.

## Проверка

Модульные тесты должны подтвердить:

1. отсутствие разрешения даёт красный треугольник;
2. постоянная ошибка даёт красный треугольник;
3. временная ошибка остаётся обычным кругом и не получает красный стиль;
4. существующие отображения Ready, Recording и Recognizing не меняются.

В собранном `.app` вручную проверяется видимость красного треугольника при
отсутствующем разрешении.
