# Исключение владельца для Preview 1.3.2

2026-11-03 в 13:07:38 UTC владелец явно поручил: «Отменить требования
ручной проверки. Опубликовать.» Решение принято после раскрытия того, что
ручной P0 не выполнен, в ответ на вопрос об исключении именно для 1.3.2.

## Область решения

- Версия: Preview 1.3.2, ad-hoc подпись, без Apple Developer ID и нотариализации Apple.
- Build: `202611031126` UTC.
- Binary source и target тега `v1.3.2`: `361feb79e437be638e9f4a1b4a05d7a3af746be5`.
- Full DMG SHA-256: `476cba2b3b505c4b1d12e3fcaea0004c901b680072702147dd05e0afb2c566fb`.
- Update DMG SHA-256: `2cccaa64db24c8a0a75e185e7fd8447031817016d7f4c1a24ee470e9a33b5284`.
- Signed manifest SHA-256: `7adb2fb6768c82102c00e38a6d35e071bedb2d69b63466a61c9b29a98ea1e376`.

Владелец отменил блокировку публикации из-за отсутствия ручного P0 только
для этого кандидата. Статус ручной проверки: **SKIPPED by owner exception,
не PASS**. Публикация остаётся Preview. Общие требования
[`MANUAL_P0_CHECKLIST.md`](MANUAL_P0_CHECKLIST.md) сохраняются для остальных
релизов; это решение не разрешает пропуск автоматических проверок, замену
модели, изменение доверенного ключа или ослабление проверки обновлений.

## Непроверенные вручную сценарии

Весь ручной gate из разделов 1–4 чек-листа не выполнялся:

- Установка Full DMG через Finder, отображение иконки, запуск из Applications,
  подготовка модели установленным приложением, первый и повторный TCC reset,
  выдача и отзыв Accessibility, Input Monitoring и Microphone, новая build identity.
- Физические 20 коротких и 20 длинных Fn/Globe, назначенная клавиша,
  комбинации и autorepeat, потеря/восстановление event tap, отказ старта capture.
- Реальный микрофон и распознавание, пустой результат, ASR timeout/retry/cleanup
  и выход при зависании, пунктуация и пробел в конце, secure-field и focus-change
  отказы, вставка в нативные поля, HTML input/textarea/contenteditable,
  Chrome, Yandex, ChatGPT/Codex и встроенные браузеры, сохранение clipboard
  representations и новых пользовательских данных. AppKit/WebKit fixture
  собран, но не запущен.
- Реальный выбор Full/Update установленным updater, отказы manifest/network/
  digest/quarantine, открытие DMG и завершение приложения, замена через Finder
  и последующая миграция разрешений.

Риски Preview: эти пользовательские сценарии могут содержать дефекты,
которые не выявляются автоматическими проверками. Совместимость с конкретными
приложениями, реальная диктовка и успешное обновление этим выпуском вручную
не подтверждены. Ограничения должны оставаться в публичном описании релиза.
